This is an entry for make.fun's “Sum up 25 November's world news in one image” bounty, offering $100 in USDC. The Pillow-drawn front page is saved as entry.png, and main.ts copies it to /output/entry.png (or the directory selected by MAKEFUN_OUTPUT_DIR). The page carries 35 sourced stories with verification badges, a UTC timeline, a numbers strip and a world map.
